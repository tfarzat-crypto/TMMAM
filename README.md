# تقدير البناء — تطبيق أندرويد (Kotlin + Jetpack Compose)

تطبيق عربي (من اليمين إلى اليسار) لتقدير كميات وتكلفة المباني لعملاء المكتب: حسبة سريعة، هيكل وأساسات، مبانٍ وتشطيبات وعزل، أرض وربح، جدول زمني وتدفق نقدي، وتقرير يحمل شعار المكتب (PDF / Excel).

## طريقة البناء

### أ) من الجوال بدون Android Studio (GitHub Actions)

1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد إليه (فرع `main`).
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**.
3. بعد انتهاء التشغيل نزّل الملف `build-estimator-apk` من أسفل صفحة التشغيل، وبداخله `app-debug.apk`.
4. ثبّته على الجوال (اسمح بالتثبيت من مصادر غير معروفة).

### ب) من الكمبيوتر (Android Studio)

1. افتح المجلد `BuildEstimator` في Android Studio (إصدار Ladybug أو أحدث).
2. انتظر مزامنة Gradle ثم اضغط **Run**، أو **Build ← Build APK(s)**.

المتطلبات: JDK 17، Android SDK 35، Gradle 8.11.1 (يُنزَّل تلقائياً).

## بنية الكود

| المسار | المحتوى |
|---|---|
| `data/Models.kt` | نموذج المشروع والدول والعملات |
| `data/Defaults.kt` | المعدلات الهندسية وأسعار البداية لكل دولة |
| `data/Store.kt` | الحفظ المحلي (يعمل بدون إنترنت) |
| `calc/Engine.kt` | محرك الحسابات — كل المعادلات هنا |
| `report/` | توليد التقرير HTML/CSV والطباعة والمشاركة |
| `ui/` | الشاشات (Compose) |

## تنبيه مهم عن الأرقام

- **المعدلات** (م³/م²، كجم/م³، …) معدلات تقديرية شائعة وضعتها كنقطة بداية، وكلها قابلة للتعديل من شاشة «المعدلات».
- **الأسعار**: سعر الحديد في السعودية ومصر فقط مأخوذ من مصدر منشور (نوفمبر 2026). باقي الأسعار **افتراضية غير موثّقة** ومعلَّمة بذلك داخل التطبيق، ويجب مراجعتها قبل إخراج أي تقرير لعميل.
- **سوريا** (الدولة الافتراضية): الأسعار تُدخل بالدولار، وأرقام البداية محوَّلة من أسعار السعودية (÷ 3.75) وليست أسعار السوق السوري. يمكن عرض النتائج بالليرة السورية بعد إدخال سعر الصرف من «بيانات المشروع».
- الدول الأخرى (ومنها أمريكا بالدولار) تبدأ أسعارها بصفر حتى تُدخل يدوياً.
- اسم المكتب والمهندس ثابتان في الكود (`data/Models.kt` ← `Office`).
